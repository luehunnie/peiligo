## 11. 遗留问题与风险

1. **Git 无提交、无远程**：工作区尚无任何 commit，也未配置 origin 远程。
   本次按约定不自动提交、不自动推送，需人工审查后再决定首次提交与远程配置。
2. **npm 缓存位置**：本机默认 npm 缓存目录对当前用户不可写，安装时已将缓存
   重定向到可写位置；这不影响项目本身，仅为本机环境注意事项。
3. **Vite 默认绑定 localhost**：Vite 默认监听 `localhost`（解析为 IPv6 `::1`），
   使用 `127.0.0.1` 直接访问可能不通，验证时已用 `localhost` 访问。

以上均为环境与流程层面的事项，不影响 M0 骨架的功能正确性。
