## 4. 关键技术口径与留痕（Wagtail 7.4 源码亲证）

1. **base_form_class 无字符串解析**（wagtail/admin/panels/page_utils.py 传类）→ 全部传类引用；departments.models 顶层导入 forms、forms 迟导入 Department 断环。
2. **AdminPageChooser target_models 传字符串在首位 app 加载期解析即 AppRegistryNotReady** → home/models.py 类直引五内容页（注释留痕）。
3. **创建期父级可得性**：Wagtail CreateView 传 parent_page 给表单 → ParentContextPageForm 注入；add_child 期 treebeard 先置 path 后 save(clean=True)→full_clean，`get_parent_container` 以 `page.path` 为准（pk None 但 path 已定位）——测试亲证。
4. **M2M 表单校验时序（SoftwareTool platforms ≥1）**：Django `construct_instance` 仅遍历 `_meta.fields`（不含 many_to_many，M2M 回填在 save_cluster_m2m）→ clean 内 `platforms.all()` 在创建表单校验期恒空，不区分会误拒合法提交（实测复现）。终态双闸：blank=False 表单字段必填（表单流）＋clean 模型兜底（仅对 cluster 内存值已就位或已保存状态判定，注释留痕实测口径）。**编辑流已保存状态的模型闸行为 B 阶段后台实测复核**（与设计审查 taggit clean 闸同款 B 阶段口径）。
5. **taggit 无 `__set__` 描述符**：构造器传 tags 存裸 list；模型直建须 `page.tags.set(...)` 落 cluster。校验闸真实拦截面＝cluster 持未保存 Tag 实例（经 through 项构造）；自由字符串经 taggit `_to_tag_model_instances` 会 get_or_create 即时落库——**防自由字符串的实际屏障是表单闸（CM-08 复选词表），校验闸防集群未保存项**，此为 taggit 官方行为，非设计偏差。
6. **RichTextBlock 表单值是 Draftail contentstate JSON**（非 HTML 字符串，exporter json.loads 亲证）→ 测试 helper 按官方分片键（count/deleted/order/type/value）＋contentstate JSON 构造，模型直建路径用 StreamValue 元组。
7. **既有测试两处更新（设计驱动，非测试放松）**：test_ia_structure/test_ia_frontend 的容器 fixture 增 department（§4 容器必填绑定）；`test_container_allows_no_subpages_yet`（M2.1 空占位）→ `test_container_subpages_are_five_content_types`（§1.4 终态五类），docstring 留痕演进。
