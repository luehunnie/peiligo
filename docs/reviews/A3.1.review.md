## 6. 发现清单

**F-1（P2，FIX 必修）容器跨板块移动/递归复制不复检子内容页——§1.4 冻结约束破口。**
`departments/wagtail_hooks.py` 容器分支仅校验目标为 SectionPage＋同板块无部门撞车，不对其子树内容页按新板块复检板块白名单（§1.4）/部门一致性（§4）/活动字段必填性（§7.2）；递归复制路径（wagtail 原生 `save(clean=False)`）同构缺位。SSOT §1.4-2 冻结约束为"**任何时点**树上不存在违反本表板块级限制的内容页"，且明定移动路径须"强制同一规则"——子树随容器换板块即内容页的板块外移动，属该机制的实现不完整。危害：总管理员一次常规后台移动/递归复制即产生违约页面，且该页自此不可再编辑保存（clean 永拒），只能靠再移动/删除脱困。**修复建议（小改，均在既有 hooks 模块内）**：容器移动分支对子树内容页以 `clean_content_page(page, errors, parent_override=新容器)`＋Notice/Article 加 `clean_event_fields` 同口径复检，违规取消移动；`before_copy_page` 钩子对 recursive 容器复制同检（或容器复制目标板块须与其源板块一致）。
**升级判定**：不触发 Human 裁决（无需求歧义/无载体变更/无跨批依赖/无权限模型改动）——实现完整性缺陷，返回实现者修复＋补测（MoveHookTests 增容器跨板块携子复检用例）后复审此单点即可，其余结论不受影响。

**F-2（P4）chronicle 板块活动字段强制空未覆盖 `event_is_online`。**
§7.2"五个存储字段必须全部为空（clean 对任何已填活动字段报错）"实现为四字段检查（start/end/location/registration_url），布尔位 `event_is_online=True` 在纪事板块可通过 clean（表单流实测通过）；代码注释与测试文档均自称"五字段强制全空"，行为与表述不一致。无功能影响（前台仅在 event_start_at 存在时渲染活动区；面板隐藏属 B 阶段）。建议随 F-1 修复一并补 `event_is_online` 为 True 即报错＋用例。

**F-3（P4）自检报告两处表述精度。**
①A3.1.impl.md §1.4"此前已含 wagtail.contrib.settings/table_block（A3.1 前置）"易误读为基线已有——diff 亲证两者均为本批 860b439 新增（正是设计 §11.1 落位提示的落实，行为正确，仅措辞需标明"本批首提交新增"）；②ruff format 计数 90 与本审查 91 之差＝docs/*.md 内嵌 python 块计入 format 范围（自检报告自身落盘即 +1），双绿不受影响，留口径说明即可。
