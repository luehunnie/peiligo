## 2. 关键实现裁决与登记（不阻断、待审查裁量）

1. **板块过滤谓词＝`path__startswith` 而非 `descendant_of`**：`descendant_of` 展开含 `depth__gte` 列，冻结表 A 无 `FilterField("depth")` → check() 三后端同报 FilterFieldError（探针亲证）。改用 `path__startswith=<板块.path>` 路径区间——五类型对象域上与子树语义等价（容器/结构页本就经逐类型入口结构性排除，锚点 SectionPage 自身不在域内），表 A 逐字不动、PS-32 仍成立。**登记**：若后续设计侧坚持 `descendant_of` 字面形态，须表 A 增 `FilterField("depth")`（走设计修复环，本批禁改文档）。
2. **wagtailsearch.W001 ×5（新增告警，manage.py check 仍 exit 0）**：Wagtail 检查器建议子类 `search_fields = Page.search_fields + [...]` 承接基类；批令①"严格按 §20 表 A/B"＝精确声明形态（事实 2 逐项自含），与该建议互斥。10 条 treebeard.E001 系 A2.1 既有口径不变；总 issues 10→15。**登记**：处置选项（a）接受为文档化告警（现状）；（b）设计修复环改表 A 为 `Page.search_fields + [...]` 形态。选（a）因批令明令严格表 A/B。
3. **词表 M2M 索引时机缺口（上游限制）**：cluster M2M（tags.set()/platforms）在 post_save 即时索引任务之后提交 → 发布时点标签名/平台名缺席 IndexEntry 文本（探针 dump 亲证：body_text 缺标签名，update_index 后补全）；FK 词表（discipline/material_type/category/department）不受影响。测试先 `update_index` 再断言 M2M 名文本；生产 update_index 接线/调度归 MB10（§24.4）。tag 过滤（slug/name 谓词）不受影响（纯 ORM join）。
4. **中文检索只测契约不测质量（批令口径）**：E2 现配置（PG FTS＋simple）下 CJK 连续串成单 token——子串查询不命中＝已文档化语义（§20.2）非缺陷；测试一律整 token（如完整标题/完整地点名）。E1/E3 差异裁决归 M6.x，本批零后端切换、零新依赖（PS-38：D7 门不越）。
5. **taggit join 实测锚点（§21.2 预留）正面落定**：`RelatedFields("tags")` 经 modelsearch 编译器 M2M 匹配（taggit 2-hop path_infos）实测可 join——`tag=` 谓词与 q=标签名文本双路径测试全绿，无需启用"pk__in 预解析回退"。
6. **PS-34/PS-39 等不越界**：ARCHIVE-SEARCH（含 expired）未实现未声称（expired 一律 excluded，测试坐实）；零时间参数。
