# Peiligo 部门编辑操作手册

写给:**各部门获得网站账号、负责发布内容的老师与同事。完全不需要编程知识——你只需要一台电脑、一个浏览器和自己的账号。**

这篇手册覆盖后台操作的每一步:登录、认识后台、新建内容、插图、发布、修改、下线,以及常见问题。操作背后的业务规则(发什么、发到哪)见 [CONTENT_PUBLISHING_GUIDE.md](CONTENT_PUBLISHING_GUIDE.md)。

> **先说一句安心话**:你在这个系统里能做的事是有限的、安全的——你只能看到和操作**自己部门**的内容,做不出「把别的部门搞乱」或「误删全站」这类操作。放心按手册点。

---

## 1. 三分钟快速流程

急着发布一条简单内容?就这五步:

1. 打开网站后台地址(形如 `https://你的网站域名/admin/`),输入账号密码登录;
2. 左侧点「页面」,在「首页 → 你的板块 → 你的部门」下点「添加子页面」,选内容类型;
3. 填标题、发布部门、摘要、正文;
4. 点底部「预览」检查,没问题点「发布」;
5. 回到前台把页面打开看一眼。

每一步的细节、特殊情况、常见报错,往下看。

## 2. 登录

- **后台地址**:`https://你的网站域名/admin/`(具体域名以管理员通知为准;收藏到浏览器书签)。后台与前台是同一个网站,只是多了 `/admin/` 这一层门;
- **账号**:每个部门只有一个账号,由管理员统一创建后交给部门保管,不要多人私下传用;
- **密码要求**:至少 12 位。这是全站统一的安全要求——系统会用自动化的方式抵御「拿字典猜密码」的攻击,长密码是第一道防线。建议用「一句只有部门知道的话」当密码,比如四五个词连成的短语;
- **输错了会怎样**:连续输错多次,系统会暂时限制这个账号登录(约 15 分钟后自动恢复)。这不是故障,是防盗机制——停下来核对密码,或联系管理员;
- **登录有效期**:登录状态约 24 小时,之后需要重新登录;
- **管理员在后台为你设置或重置密码后**:系统会要求你先自己设置一个新密码,才能继续使用(账号由管理员经命令行创建的则没有这一步)。按提示操作即可。

## 3. 认识后台

登录后看到的界面(简体中文)主要分三块:

| 区域 | 是什么 | 你主要用到的 |
|---|---|---|
| 左侧菜单 | 功能入口 | **「页面」**(你的全部工作)和**「图片」**(部门图片库) |
| 中间列表 | 点进菜单后的内容列表 | 页面树、图片列表 |
| 底部按钮条 | 编辑页面时的操作 | 「保存草稿」「预览」「发布」 |

你**看不到**「文档」「片段」「设置」等菜单,也看不到其他部门的内容——这是系统有意设计的权限隔离(见 §9),不是账号出了问题。

页面编辑器右侧还有几个折叠的面板,常用的是:

- **状态**:显示这页现在是草稿、已发布还是已到期;
- **历史**:每次保存与发布都会留一条记录,可以回看;
- **设置**:定时发布与有效期在这里——「上线日期/时间」负责定时发布,「过期日期/时间」就是业务上说的「有效期」。

## 4. 找到自己部门的位置

你的内容全部放在「页面」树里自己部门的目录下:

```
首页
└── 校园纪事(板块)
    └── 你的部门(部门目录) ← 你的内容都建在这里
        ├── 某条通知
        └── 某篇文章
```

- 登录后在「页面」里看到的就是**你部门的目录**,直接在里面「添加子页面」即可;
- 只有一个「你的部门」目录、看不到别的部门——这是正常设计,每个部门都只能看到自己的目录,互不可见、互不可改;
- 如果登录后**看不到任何部门目录**,说明账号尚未被授权或目录还没建好,请联系管理员。

## 5. 新建内容(通用步骤)

1. 进入你部门的目录,点右上角**「添加子页面」**;
2. 在弹出的类型列表里**选一种内容类型**:
   - **通知页**——正式通知、有时效的消息(校园纪事、校园活动板块);
   - **文章页**——新闻、报道、不设期限的内容(校园纪事、校园活动板块);
   - **学习资料页**——课件、讲义、题库等资料(学习资料板块);
   - **软件与工具页**——推荐软件与在线工具(软件与工具板块);
   - **校园指南页**——办事流程、长期说明(校园指南板块);
   > 你能选到哪些类型由管理员为部门开通的范围决定;类型怎么选见《内容发布指南》§3 速查表;
3. 从**标题**开始逐项填写。各类型的字段见 §6;
4. 右侧「推荐」面板里的**缩略名**(页面链接地址)会根据标题自动生成,一般不用改;
5. 填写过程中随时点**「保存草稿」**,不怕丢;
6. 填完后点**「预览」**看实际效果,再按 §8 检查,最后点**「发布」**。

> 部分内容页底部或右侧如有「活动信息(仅校园活动板块填写)」分组——只有你的内容发布在**校园活动**板块时才需要填它,开始/结束时间为必填;发布在校园纪事板块时请不要填它。

## 6. 五种内容怎么填

### 6.1 通知页 / 文章页

两者的字段完全一样,只差一条规则:**通知页必须填有效期**(到期自动归档),文章页可不填(长期在线)。

| 字段 | 必填? | 怎么填 |
|---|---|---|
| 标题 | 必填 | 一句话说清事情,不加书名号、不堆感叹号 |
| 发布部门 | 必填 | 选你自己的部门(下拉选择) |
| 摘要 | 必填 | 1–3 句话概括;会显示在列表里,别写成第一段正文 |
| 正文 | 必填 | 见下方「正文编辑器」 |
| 图片 | 可选 | 打开选择窗口后点「上传」当场传一张;建议 16:9 或 4:3 的横图 |
| 轮播封面图 | 可选 | 仅当内容可能被选入首页轮播时才需要准备;推荐 1600×600(8:3)横图;不上传不影响发布 |
| 附件 | 可选 | **部门账号当前不能自行上传文档附件**;确需附件请联系管理员上传后挂入 |
| 外部链接 | 可选 | 填完整网址(以 http:// 或 https:// 开头,建议 https);填了它,这一页就是「外链转介绍页」性质,学生点击后会先看到确认提示 |
| 受控标签 | 可选 | 只能从已有标签里选;需要新标签请找管理员 |
| 活动信息(仅校园活动板块) | 活动必填 | 开始时间、结束时间必填;线下活动必须填活动地点;纯线上活动勾选「线上活动」;有报名页可填报名链接 |
| 有效期 | 通知必填 / 文章可选 | 编辑页右侧「设置」面板中的「过期日期/时间」字段;必须是未来时间。建议:截止类通知 = 截止日当天稍晚;一般通知 = 事项结束后一两周 |

> 「图片」(正文插图)与「轮播封面图」是两个独立字段:前者负责页面内的插图展示,后者只在这条内容有资格被管理员选上**首页轮播**时才会用到。两者都不填,内容照常发布。

**正文编辑器**(通知/文章/资料/软件工具共用):正文不是一整块文本框,而是「一块一块」加出来的。点「+」添加块,常用的有:

- **标题**:分 H2(次级标题)、H3(三级标题)——页面大标题用顶部的「标题」字段,这里只放文内小节标题,一般用 H2;
- **正文段落**:正常打字,工具条支持**粗体**、**斜体**、**插入链接**、**编号列表**与**项目列表**;
- **图片**:插入图片(在弹出的选择窗口里点「上传」当场传图);
- **附件**:插入文档附件(同上,需管理员协助上传);
- **表格**:简单的行列数据;
- **外部链接**:文内指向外部网站的一条链接(链接地址 + 链接文字)。

建议一篇文章至少有一个段落块;纯图片请配文字说明。

### 6.2 学习资料页

| 字段 | 必填? | 怎么填 |
|---|---|---|
| 标题 | 必填 | 资料名称,如「高等数学期末复习提纲」 |
| 发布部门 | 必填 | 你的部门 |
| 学科·专业方向 | 必填 | 从列表选;没有合适的选项请找管理员建词表 |
| 资料类型 | 必填 | 课件 / 讲义 / 题库 / 模板等,从列表选 |
| 摘要 | 必填 | 这份资料是什么、适合谁 |
| 正文 | 必填 | 使用说明、目录、注意事项等 |
| 外部链接 | 可选 | 资料存放在外部网盘时填 |
| 附件 | 可选 | 需管理员协助上传 |
| 受控标签 | 可选 | 从已有标签选 |
| 轮播封面图 | 可选 | 仅当内容可能上首页轮播时准备;推荐 1600×600(8:3)横图 |

学习资料页**没有**有效期(资料长期有效),也没有「活动信息」。

### 6.3 软件与工具页

| 字段 | 必填? | 怎么填 |
|---|---|---|
| 软件或工具名称 | 必填 | 顶部的「标题」字段 |
| 发布部门 | 必填 | 你的部门 |
| 适用平台 | 必填 | 至少选一个:Windows / macOS / Android / iOS / 网页版等 |
| 正文 | 必填 | 介绍用途、使用方法;**没有附件块**(网站不托管安装包) |
| 来源链接或第三方网盘链接 | 必填 | 官方下载页或可靠的网盘地址 |
| 授权或费用说明 | 必填 | 写清「免费」「学校已购授权」或收费情况——学生最关心这条 |
| 轮播封面图 | 可选 | 仅当内容可能上首页轮播时准备;推荐 1600×600(8:3)横图 |

### 6.4 校园指南页

指南页是一张「服务卡片」,没有长篇正文,按卡片逐格填:

| 字段 | 必填? | 怎么填 |
|---|---|---|
| 服务名称 | 必填 | 如「图书馆借书」「校医院就诊」 |
| 发布部门 | 必填 | 你的部门 |
| 指南类别 | 必填 | 从列表选;缺类别找管理员 |
| 地点 | 必填 | 具体位置,写到楼栋楼层 |
| 开放时间 | 必填 | 服务时间,如「工作日 8:00–17:00」 |
| 联系方式 | 必填 | 电话或办公地点 |
| 补充说明 | 可选 | 流程要点、注意事项(如有需要) |
| 责任来源或责任单位 | 必填 | 这份指南的信息由谁负责 |
| 维护方式 | 必填 | 「责任部门后台自维护」(你们自己更新)或「统一邮箱投稿·总管理员代维护」 |
| 最后确认日期或更新时间 | 必填 | 你**今天**核对过信息无误的日期——给学生的信任凭证 |
| 轮播封面图 | 可选 | 仅当内容可能上首页轮播时准备;推荐 1600×600(8:3)横图 |

## 7. 图片与附件

### 图片

- 支持格式:**jpg / jpeg / png / webp**;手机截图、屏幕截图(通常 png)都可以;
- 系统会自动检查文件类型是否与实际内容一致,改名冒充没用——遇到「无法识别」提示时,换一张正常的图片文件;
- **上传位置**:两个入口——①左侧「图片」菜单进入部门图片库管理;②编辑内容时,在图片字段或正文「图片」块的选择窗口里点「上传」当场传图。日常推荐入口②:传完即插入;
- 上传时会让你填**标题**——认真填,这是图片的无障碍描述(视障读者的读屏软件会读它),也是日后搜索图片的依据;
- 图片库按部门隔离:你只能看到和上传自己部门的图片;
- 建议:横图(16:9 或 4:3)优先;单张几百 KB 到 1–2 MB 即可,不必传原始大图;
- 「轮播封面图」字段(五类内容页均有)是**可选项**:仅当这条内容可能被管理员选入**首页轮播**大图时才值得上传,推荐 1600×600(8:3)横图;普通内容的正文插图仍按上面的 16:9 / 4:3 建议即可。

### 附件(文档)

- 支持:**doc / docx / pdf / ppt / pptx / xls / xlsx**,单个文件不超过 **20 MiB**;
- **重要:当前部门账号没有上传文档的权限**。如果内容需要附件,请把文件与「挂在哪条内容上」一并告诉管理员,由管理员上传后你再在页面里选择挂入;
- 系统同样会自动检查文件类型与实际内容是否一致;损坏或格式不符的文件会被拒绝,并给出中文提示。

### Word 与 PDF 文件(没有自动导入)

后台**没有**「上传 Word/PDF 自动生成文章」的功能——正文必须用编辑器逐块录入。遇到 Word/PDF 材料时这样处理:

- **Word 文稿当底稿**:在 Word 里定稿后,把文字复制粘贴进「正文段落」块;文内小标题改用「标题」块(H2/H3),数据表用「表格」块重录。Word 里的颜色、字体、分栏等排版不会被带过来——工具条只有粗体、斜体、链接与列表;
- **PDF 作为可下载资料**:把 PDF 的简介写成一页普通内容(「正文段落」块),PDF 文件本身交给管理员作为附件上传后挂入,学生打开内容即可下载;若 PDF 已放在外部网站,改用「外部链接」字段并写清说明;
- **想把 PDF 内容直接做成站内文章**:需要人工把内容提取出来,按标题/段落/表格重新组织录入。网站不会把 PDF 原样转成页面,也不建议整页贴 PDF 截图——学生无法复制其中的文字。

## 8. 预览与发布

### 预览

编辑器右下角点**「预览」**,弹出学生实际看到的页面效果。预览不等于发布——学生此时还看不到。

### 发布前 30 秒检查

- [ ] 标题、摘要无错别字,日期时间正确;
- [ ] 发布部门选对了;
- [ ] 正文块顺序正确,图片显示正常;
- [ ] 外部链接能打开;
- [ ] 通知页:有效期已填且是未来时间;
- [ ] 活动内容(校园活动板块):开始/结束时间、地点已填;
- [ ] 「推荐」面板里的缩略名(链接地址)未被误改(默认自动生成,无需动)。

### 发布

- 点**「发布」**——在弹出的窗口里二选一:
  - **立即发布**:保存并马上上线,学生立刻可见;
  - **定时发布**:设定将来的上线(和/或下线)时间,保存后到点由系统自动执行。适合「周一 8:00 准时公布」;注意时间表只有在选择了「定时发布」选项后才会生效;
- 发布成功后,编辑页右侧「状态」面板会显示线上版本,点「实时查看」即可打开前台页面复核;
- **只保存不发布** = 草稿。草稿随时可以继续改,学生永远看不到。

## 9. 权限:你能动什么、不能动什么

| 操作 | 你可以吗 |
|---|---|
| 在本部门目录下新建内容 | ✅ |
| 编辑、发布、下线**本部门**的内容 | ✅ |
| 上传、管理**本部门**的图片 | ✅ |
| 上传文档附件 | ❌(联系管理员) |
| 看到/操作其他部门的内容 | ❌(互相不可见) |
| 编辑首页、板块页、部门目录本身 | ❌(结构由管理员统一维护) |
| **删除任何内容** | ❌(任何部门账号都没有删除权) |
| 管理账号、标签、词表、首页推荐位、首页轮播、站点设置 | ❌(仅管理员) |

这不是不信任,而是职责分离:**删除是高危且不可恢复的操作**,统一收归总管理员;部门内容的日常「退场」用「下线」就够了。需要删除时(例如测试数据、明显错误发布),联系管理员处理。

## 10. 修改已发布的内容

1. 在「页面」里点开那条内容,直接编辑;
2. 改完点「发布」——修改立即生效;
3. 每次保存/发布都记录在右侧「历史」面板;万一改错了,可以在历史里查看过往版本内容,照着恢复(历史不提供一键替换时,联系管理员协助);
4. 改标题会改变页面链接地址——已经被转发出去的旧链接可能失效,重要内容尽量不改标题;确实要改,通知发过链接的人。

## 11. 下线、到期与删除

- **手动下线**:编辑页面的操作菜单里选**「取消发布」**(下线)——内容立刻从前台消失,但数据完整保留,之后修改可重新发布;
- **到期**:通知页到达有效期后,系统自动把内容从列表退到「历史归档」,打开时页面顶部显示「已过期」横幅。**不需要你做任何操作,内容也不会被删除**;想让它继续在线,重新发布并填一个新的未来有效期;
- **删除**:你没有删除权;**不确定时永远不要请求删除**——下线/到期已经让内容对学生不可见,足以应对绝大多数情况。仅当确属测试数据、违法内容等极少数情形,联系管理员评估处理。

## 12. 常见问题(FAQ)

**Q1:登录不上,提示账号或密码错误?**
先确认账号是本部门的正式账号;密码区分大小写、至少 12 位。连续输错多次会暂时限制登录,等约 15 分钟再试。仍不行联系管理员重置(重置后首次登录需自行设置新密码)。

**Q2:点「添加子页面」看不到某种类型(比如「学习资料页」)?**
你部门目录所在板块只开放对应的类型(纪事/活动板块下没有资料页)。如果类型与板块不匹配,先想清楚该发到哪个板块;需要开通请找管理员。

**Q3:「发布部门」下拉里没有我的部门?**
该字段必须与内容所在目录一致。如果确实没有,说明账号或目录还没配置好,联系管理员。

**Q4:图片上传被拒绝,提示无法识别或格式不对?**
只支持 jpg / jpeg / png / webp。把文件扩展名改名来「伪装」是不行的——系统会检查文件真实内容。用原始图片文件重试。

**Q5:附件传不了?**
部门账号当前没有上传文档的权限,请把文件交给管理员上传。详见 §7。

**Q6:点了「保存草稿」,前台怎么看不到?**
草稿只有后台能看到。要让学生看到,必须点「发布」。

**Q7:定时发布没生效?**
检查两点:弹出窗口里是否选择了「定时发布」选项(只填时间、不选它是不生效的);设定的上线时间是否真的已过。系统按分钟级周期执行,到点后一两分钟内上线。

**Q8:发布后发现错别字/错误信息?**
立即编辑改正并重新发布,前台即刻更新。错误已被人转发无需处理——链接不变,改正后打开就是新内容。

**Q9:不小心把内容「取消发布」了,怎么办?**
没有损失:内容还在后台。修改(如需要)后重新点「发布」即可恢复上线。

**Q10:内容已经「已过期」,还能恢复吗?**
能。打开该内容,重新发布并填写新的未来有效期(通知)或清空有效期(文章),它就回到正常列表。

**Q11:改了标题,原来的链接打不开了?**
标题改变会导致链接地址变化。把新链接发给对方,或请管理员设置跳转。

**Q12:正文里想贴 Excel 大表?**
用「表格」块录入关键行列,或把完整文件做成附件(联系管理员)。不要把表格截图当图片贴——学生无法复制内容。

**Q13:要发的内容两个板块都合适(比如既是通知又涉及活动)?**
选主要属性:有明确开始/结束时间 → 校园活动板块;否则 → 校园纪事板块。一条内容只发一处,不要重复建页;确有跨板块展示需求,联系管理员。

**Q14:忘记内容是不是已经发过?**
「页面」列表里每条内容都带有状态标记(草稿、发布、已过期等字样);也可以在前台或站内搜索用标题关键词查一下。

**Q15:我有一份 Word 文档 / PDF,能直接上传变成一篇文章吗?**
不能——系统没有 Word/PDF 自动导入功能。Word 文稿请在软件里定稿后,把文字复制进正文编辑器;PDF 可以作为附件(联系管理员上传)或外部链接提供,详见 §7「Word 与 PDF 文件」。

## 14. 禁止事项

- ❌ **不发布涉密、内部或未定稿内容**——本网站面向全校学生公开;
- ❌ **不发布学生个人信息**(如完整学号+姓名组合、身份证号、家庭信息);
- ❌ **不发布未经部门负责人确认的内容**——发布即代表部门名义;
- ❌ **不在正文里粘贴无关的、未经验证的外部链接**——所有外链都会经确认页暴露给全校;
- ❌ **不使用共享传阅的弱密码**,不把账号密码发给他人代操作;
- ❌ **不尝试请求删除内容**——不确定时选择「下线」;
- ❌ **不重复发同一内容到多个板块**。
